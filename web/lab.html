How the experiment works

The first 20 training draws initialize each method. Each remaining training draw is predicted using only earlier draws. The method with the most exact 6/6 validation matches is selected. Ties use total number matches, then draws with at least two matches, then listed method order. These tie breakers choose an experimental candidate; partial matches do not meet the objective. Target results never select the recommended method.

The frozen evaluation uses the same training history for every target. Walk-forward evaluation adds each target only after scoring its prediction. Six distinct numbers are chosen from 1–55; fixed seed 655 resolves score ties and makes the balanced search repeatable.

Random-match probabilities use the hypergeometric formula: P(K = k) = C(6,k) C(49,6−k) / C(55,6). The sample is small, and no formula here establishes a reliable way to derive lottery outcomes. Only all six numbers in the same ticket and corresponding target count as success. Partial matches are diagnostics only.
